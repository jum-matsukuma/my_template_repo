# 公開解法の整理

`/kaggle-research` で取得した notebook / discussion / writeup から、
**手法を分類して要点をまとめる**場所。

## 書くときの原則

- **コードを丸写ししない。** ライセンスを確認し、要約と分類に留める
- **数値は出所付きで書く。** 「CV 8.5」ではなく
  「作者申告 CV 8.5（notebook `<ref>` v12 のセル出力）」
- **自己申告 CV をそのまま信じない。** ベンチマークにするなら自分で回して測る。
  プロット内にハードコードされた定数が「実測 CV」として流通していた例がある
- **発言の帰属を確認する。** 運営の発言と参加者の推測は重みが違う。
  discussion では原文で誰の発言かを見る
